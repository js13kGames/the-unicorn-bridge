# The Unicorn Bridge

**The Unicorn Bridge** is a fast-paced, mobile-first game about building a rainbow bridge to help a unicorn make it home.

## How to Play

Watch the required color, then **swipe the matching bubble upward**.

- Match the required color to build the bridge.
- Choose the wrong color and you lose a life.
- React too slowly and you lose a life.
- Collect Hearts for extra lives.
- Collect Silver bubbles for bonus points.

Each level increases the challenge. Can you beat the **Boss Level?**

## Controls

**Touch and swipe upward** on the matching bubble.

## Built With

- HTML5 Canvas
- Vanilla JavaScript
- CSS
- Web Audio API


Have fun :)
